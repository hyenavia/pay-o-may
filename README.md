# 🇮🇩 Bahasa Indonesia

**Pay o' May** adalah gim novel visual (*visual novel*) simulasi edukasi kesadaran finansial yang dirancang khusus untuk mahasiswa perantauan. Pemain berperan sebagai mahasiswa tahun pertama yang harus mengelola uang saku bulanan terbatas sebesar **Rp 2.000.000** selama 31 hari (4 minggu) di tengah berbagai tekanan sosial, godaan belanja konsumtif, dan keadaan darurat nyata.

Proyek ini dikembangkan sebagai karya gim indie edukasi kesadaran finansial oleh **Hyenavia**.

---

## 📌 Latar Belakang & Tujuan

Banyak mahasiswa perantau yang menghadapi kesulitan mengelola keuangan pribadi karena belum terbiasa hidup mandiri, terjebak ilusi belanja kemudahan *PayLater*, atau terpengaruh tekanan sosial kawan sebaya (*FOMO*). 

**Tujuan Edukasi Gim:**
1. Memberikan pemahaman konsep *Pay Yourself First* dan pentingnya pos **Dana Darurat**.
2. Mengasah kemampuan membedakan kebutuhan pokok (*Needs*) dan keinginan gaya hidup (*Wants*).
3. Mengedukasi bahaya laten bunga serta biaya layanan utang konsumtif (*PayLater*).
4. Melatih keberanian menetapkan batasan finansial yang sehat (*financial boundary*) saat meminjamkan uang kepada kawan sebaya.
5. Mengukur efektivitas media pembelajaran interaktif menggunakan instrumen kuesioner **Pre-Test** dan **Post-Test**.

---

## 🎮 Fitur Utama

- **Dukungan Dua Bahasa Penuh (Bilingual ID/EN):** Pemain dapat dengan bebas beralih antara Bahasa Indonesia dan Bahasa Inggris di menu Pengaturan (*Preferences*) kapan saja.
- **Papan Status HUD Real-Time (M-Banking Style):** Menampilkan sisa Saldo Uang Jajan dengan *progress bar* dinamis, akumulasi simpanan Dana Darurat, beban tagihan PayLater, dan status Piutang Teman.
- **Widget Panggilan Telepon Masuk Mama:** Desain kartu panggilan interaktif reaktif di pojok kanan atas dengan avatar pixel art ekspresif saat Mama menelpon dari rumah.
- **Sistem Notifikasi Smartphone Adaptif (`layar_hp`):** Simulasi pesan push notifikasi ponsel pop-up (M-Banking, toko online, chat teman, dan promo supermarket).
- **11 Titik Keputusan Finansial:** Setiap pilihan memiliki konsekuensi langsung pada arus kas, rasio kebutuhan/keinginan, tingkat stres keuangan, dan alur naratif.
- **4 Cabang Ending Cerita:**
  - 🏆 **Ending A (Bendahara Handal):** Pengelolaan seimbang, memiliki dana darurat utuh, bebas utang, dan mandiri tanpa bantuan tambahan.
  - 🛡️ **Ending B (Selamat Sampai Akhir Bulan):** Berhasil bertahan melewati bulan tanpa krisis utang.
  - ⚠️ **Ending C (Terjerat PayLater):** Menunda pembayaran belanja konsumtif hingga terjebak beban bunga majemuk di bulan berikutnya.
  - 🍜 **Ending D (Mie Instan Akhir Bulan):** Uang saku habis sebelum akhir bulan akibat belanja impulsif dan ketiadaan dana darurat.
- **Rapor Keuangan Bulanan (E-Statement):** Evaluasi performa literasi keuangan komprehensif di akhir gim, menyajikan rekap arus kas, persentase skor, analisis *Needs vs Wants*, serta predikat Gelar Finansial.
- **Estetika Retro Pixel Art:** Mengintegrasikan kit antarmuka pixel art *Everyday Life*, animasi partikel cuaca dinamis (*petals/rain*), dan efek transisi adegan kustom.

## 🔬 Metodologi Pengembangan

Pengembangan gim mengadopsi kerangka kerja **Game Development Life Cycle (GDLC)**:
1. **Initiation:** Identifikasi masalah literasi keuangan mahasiswa dan penetapan tujuan edukasi.
2. **Pre-Production:** Penyusunan skenario percabangan cerita, perancangan mekanika anggaran, dan pembuatan instrumen Pre-Test/Post-Test.
3. **Production:** Pemrograman logika simulasi Ren'Py (Python), penataan UI pixel art, integrasi audio/SFX, dan pembuatan sprite ekspresi tokoh.
4. **Testing:** Verifikasi gameplay, pengujian validitas skenario, dan uji coba pengguna (responden mahasiswa).
5. **Release:** Kompilasi multiplatform (*Windows executable* dan *Android APK/AAB*) beserta evaluasi data kuesioner.

# 🇬🇧 English

**Pay o' May** is an educational financial literacy visual novel simulation game tailored specifically for university students living away from home. Players step into the shoes of a first-year college student who must manage a limited monthly allowance of **Rp 2,000,000** across 31 days (4 weeks) amidst intense peer social pressure, seductive consumer installment traps, and real-world emergencies.

This project was developed as an educational financial literacy indie game project by **Hyenavia**.

---

## 📌 Background & Objectives

Many independent college students face severe personal budgeting struggles because they are unaccustomed to independent living, easily fall into frictionless *Buy-Now-Pay-Later (PayLater)* installment traps, or succumb to peer group social pressure (*FOMO*).

**Game Learning Objectives:**
1. Instill the foundational *Pay Yourself First* principle and the vital habit of building an **Emergency Fund**.
2. Sharpen decision-making skills between essential living costs (*Needs*) and lifestyle desires (*Wants*).
3. Demystify the hidden dangers of compounding interest, late penalties, and debt traps (*PayLater*).
4. Cultivate confidence in establishing healthy **financial boundaries** when peers request loans.
5. Measure instructional effectiveness using rigorous **Pre-Test** and **Post-Test** survey instruments.

---

## 🎮 Key Features

- **Full Dual-Language Support (Bilingual EN/ID):** Seamlessly switch between English and Indonesian at any point via the in-game Settings/Preferences menu.
- **Real-Time M-Banking Style HUD:** Features dynamic progress bars tracking allowance balance, protected emergency savings, outstanding PayLater balances, and pending peer loans.
- **Mom's Incoming Call Widget:** An interactive, adaptive phone call card displayed on the top-right corner with reactive pixel-art facial expressions when Mom calls from home.
- **Adaptive Smartphone Notification System (`layar_hp`):** Realistic pop-down phone push notifications simulating mobile banking alerts, e-commerce promos, friend chats, and supermarket flash sales.
- **11 Critical Financial Decision Points:** Every choice directly affects wallet liquidity, need-to-want ratios, financial stress levels, and branching story outcomes.
- **4 Distinct Story Endings:**
  - 🏆 **Ending A (Master Treasurer):** Balanced budgeting, intact emergency funds, zero debt, and 100% financial independence.
  - 🛡️ **Ending B (Safe Survivor):** Survived the month cleanly without turning to consumer debt.
  - ⚠️ **Ending C (PayLater Trap):** Deferred non-essential spending, trapped by compounding loan interest that drains next month's allowance.
  - 🍜 **Ending D (Instant Noodle Crisis):** Ran completely out of funds prior to month's end due to impulse splurges and zero emergency reserves.
- **Monthly E-Statement Report:** Comprehensive financial literacy evaluation at game's end detailing cash flows, score percentages, Needs vs. Wants distribution, and custom financial honorifics.
- **Charming Retro Pixel Art Aesthetic:** Powered by the *Everyday Life* UI kit, animated atmospheric weather particles (*petals/rain*), and custom scene transitions.

## 🔬 Development Methodology

Game development followed the **Game Development Life Cycle (GDLC)** framework:
1. **Initiation:** Identifying student financial literacy challenges and establishing instructional learning objectives.
2. **Pre-Production:** Drafting branching narrative scripts, formulating wallet variables, and designing Pre-Test/Post-Test questionnaires.
3. **Production:** Python scripting within Ren'Py, pixel art interface styling, audio/SFX integration, and character sprite expression design.
4. **Testing:** Verifying gameplay mechanics, testing narrative logic validity, and conducting user trials with student respondents.
5. **Release:** Compiling multiplatform builds (*Windows standalone* and *Android APK/AAB*) and evaluating survey efficacy data.

## 💻 Running from Source Code

### Prerequisites
- [Ren'Py SDK](https://www.renpy.org/latest.html) version 8.2 or higher (recommended Ren'Py 8.4+ / 8.5+).
- Computer running Windows, macOS, or Linux.

### Steps
1. Clone this repository locally:
   ```bash
   git clone https://github.com/hyenavia/pay-o-may.git
   ```
2. Open the **Ren'Py Launcher**.
3. Add the `Pay o May` project folder to your Ren'Py project directory list.
4. Select **Pay o' May** and click **Launch Project**.

### Controls
- **Left Click / Space / Enter:** Advance dialogue or select choices.
- **Mouse Wheel (Scroll Up):** View previous dialogue history (*backlog*).
- **Esc:** Open Pause Menu (Save, Load, Options, Help, About).
- **Top Quick Bar:** Fast access to Quick Save, Load, and Preferences (Audio, Display, Language).
